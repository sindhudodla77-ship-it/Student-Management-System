# Student Management System

## Project Description
The Student Management System is a simple web-based project developed using HTML, CSS, and JavaScript. It provides a homepage and a student registration form to enter and display student details.

## Objectives
- To create a simple student registration webpage.
- To collect student information through a form.
- To display the entered student details.
- To practice HTML, CSS, and JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub Pages

## Features
- Simple and user-friendly homepage.
- Student registration form.
- Student Name field.
- Roll Number field.
- Course field.
- Email field.
- Registration success message.
- Display of entered student details.

## How to Use
1. Open the website.
2. Click on Student Registration.
3. Enter the student name.
4. Enter the roll number.
5. Enter the course.
6. Enter a valid email address.
7. Click the Register button.
8. View the registration success message and entered details.

## Project Files
- index.html - Homepage.
- style.css - Website styling.
- registration.html - Student registration form.
- README.md - Project documentation.

## Limitations
This project displays the entered student details on the webpage. It does not permanently store student information because a backend and database have not been implemented.

## Future Enhancements
- Add a database to store student records.
- Add student login and authentication.
- Add options to edit and delete student records.
- Develop a backend for managing student information.

## Conclusion
The Student Management System is a beginner-friendly web development project that demonstrates the use of HTML, CSS, and JavaScript to create a student registration form.
